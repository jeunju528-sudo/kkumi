## 정해진 것
- 개수 20개, 코드는 `KK` + 4자리 번호
- 유형 구성: 안정형 8 / 롤러코스터형 8 / 한방형 4 (`decisions/029` 초기값)
- 이름은 개발자가 확정 (2026-10-07)

## 정해지지 않은 것
- 종목별 유형 배치: 기록 없음. 구현할 때 정한다
- 종목별 시작가와 호가 단위: 프론트 목업의 값은 화면 확인용 임의 값. 실제 시작가 대역은 개발자 설정 (`decisions/020`)
- `Stock` 엔티티의 `market`(KOSPI/KOSDAQ)을 가상 종목에도 둘지: 기록 없음. 구현할 때 확인

## 이름 확인 범위
- 웹 검색으로 같은 이름의 기업·브랜드가 있는지만 확인함 (2026-10-07). 같은 이름은 찾지 못했고, 발음이 비슷한 기업·브랜드가 나온 이름은 몇 개 교체함
- KIPRIS 상표 검색은 하지 않음. 검색에 안 나왔다고 상표가 없다는 뜻은 아님
- 이름에 은행·증권 단어를 쓰는 것이 금융 관련 법령상 제한되는지는 확인하지 못함 (기록 없음). 해당 단어는 이름에서 뺌
