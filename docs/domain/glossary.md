# 용어 사전

도메인 용어의 정확한 의미. 코드나 문서에서 이 용어를 쓸 때는 여기 정의를 따른다.
규칙의 최종 기준은 CLAUDE.md "도메인 규칙 (확정)". 이 문서는 그 상세 정의다.

## 돈과 투자

| 용어 | 의미 | 코드 이름 |
| --- | --- | --- |
| 시드머니 | 가입 직후 1회 고르는 시작 자금. 500만원 / 5,000만원 중 하나 | `SeedMoney` |
| 현금 | 주식 매수와 집 결제에 쓰는 돈. 주식은 현금으로만 살 수 있고, 집 결제도 현금에서만 차감함 | `Member`의 현금 |
| 보유 종목 | 내가 가진 종목과 수량, 평균 매입가. 매수·매도 때 거래 이력과 함께 갱신함 (ADR 011) | `StockHolding` |
| 거래 이력 | 매수·매도 기록. 한 테이블에서 `trade_type`으로 구분함 (ADR 012) | `TradeHistory`, `TradeType` |
| 주식 평가액 | 보유 종목을 현재 시세로 평가한 금액 | |
| 평가액 | 현금 + 주식 평가액. 집을 살 수 있는지 판단하는 기준 | |
| 시세 (주식) | 게임 안의 종목 현재가. 서버가 만드는 가상 시세이고 실제 시세 데이터는 쓰지 않음. 종목도 실제 기업과 무관한 가상 종목임. 변동 방식은 ADR 029. `StockPriceProvider` 인터페이스로만 조회하고 로그인 사용자에게만 노출함 (ADR 020) | `StockPriceProvider` |

## 아파트

| 용어 | 의미 | 코드 이름 |
| --- | --- | --- |
| 실거래가 | 국토부가 공개하는 아파트 실거래 기록. 계약이 끝난 기록이라 매물(호가)은 없음 | `AptDeal` |
| 시세 (아파트) | 최근 6개월 실거래가. 6개월 안에 거래가 없는 단지는 추천에서 제외함 (ADR 015) | |
| 단지 | 아파트 단지 | `AptComplex` |
| 거래 | 실거래 한 건. (단지 id, 전용면적, 층, 거래금액, 계약일)로 구분함 (ADR 018) | `AptDeal` |
| 집 | 사용자가 산 아파트 거래. 거래(`AptDeal`)를 참조하고, 같은 거래를 여러 사용자가 살 수 있음 (ADR 016) | `House` |
| 가짜 대출 | 집값의 60%를 대출로 가정하는 게임 설정. 실제 대출이 아니며 별도 법적·금융 의미 없음 | |
| 살 수 있는 집 | 평가액이 집값 × 40% 이상인 집. 추천 기준임 | |
| 집 추천 | 살 수 있는 집을 카드로 보여주는 것. 카드 버튼은 3가지 상태: 현금 충분(계약하기) / 평가액은 되지만 현금 부족(주식 팔러 가기) / 평가액도 부족(N원 모자라요) | |
| 집 결제 | 집값의 40%를 현금에서 차감하는 것. 현금이 모자라면 사용자가 직접 주식을 팔아 현금을 만들며 자동 매도는 없음 | |

## 연출과 성장

| 용어 | 의미 |
| --- | --- |
| 변신 4단계 | 보유 집 수로 정해지는 단계. 걸뱅이(0채) / 서민(1채) / 졸부(2~4채) / 갑부(5채 이상) |
| 계약서 | 집 사기를 확정할 때 보여주는 연출 (도장 찍기, 변신 알림, 자랑하기 버튼). 별도 법적·금융 의미 없음 |
| 내 마을 (도감) | 산 집을 모아 보는 화면. 다음 변신까지의 진행도와 빈 슬롯을 보여줌. 집 팔기는 없음 |
