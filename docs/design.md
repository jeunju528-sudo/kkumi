# design.md — 꿈이 UI/UX 규칙서 (v0.2 최종)

> UI 작업 전에 이 파일을 반드시 읽을 것. 어긋난 결과가 나오면 코드보다 이 파일을 먼저 고친다.
> 기준 시안: "꿈이 UI 시안 v0.2" (11개 화면, 3-3 내 거래 2026-10-07 추가). 값이 헷갈리면 시안의 값을 그대로 쓴다.
> 도메인 규칙은 CLAUDE.md가 우선한다.

## 1. 한 줄 방향
"읽는 정보는 모던하게, 보는 것은 픽셀로."
숫자·차트·폼은 깔끔한 모던 UI, 배경·캐릭터·집·헤더·칩은 귀여운 픽셀 일러스트.
재미는 일러스트와 카피와 연출에서 내고, 정보 영역에서는 내지 않는다.

## 2. 레퍼런스
가져올 것 (구조와 분위기만, 에셋 복제 금지)
• Dave the Diver: 상단 HUD 칩, 퀘스트 패널, 시계형 위젯, 낮/저녁/밤 색감
• Game Dev Story: 작은 스프라이트로 보여주는 성장, 숫자 팝업, 단순한 창 형태의 메뉴
가져오지 않을 것

• 게임 캐릭터, 로고, 스프라이트 등 원본 에셋

## 3. 화면 구성 (v0.2)
흐름: 1 시작(카카오 로그인) → 1-1 시드 선택 → 2 홈 → 3 종목 목록 → (3-1 종목 검색) → 3-2 사기·팔기 → 4 부동산 → 5 계약서 → 6 내 마을
보조: 3-3 내 거래 (투자 화면·홈 평가액 카드에서 진입)
• 1 시작: 제목 "인생역전 VS 인생여전"(도트 글씨), 카카오로 시작하기 하나만. ID 로그인 없음. 시드 금액은 여기서 고르지 않는다.
• 1-1 시드 선택: 가입 직후 1회. 500만원 / 5,000만원 카드 중 하나를 고르고 "N원으로 시작하기"로 홈 이동.
• ★ 변신 4단계: 걸뱅이 → 서민 → 졸부 → 갑부 (집 0 / 1 / 2~4 / 5채 이상). 단계명과 조건 배지만 표시, 설명 문구 없음.
• 2 홈: 픽셀 마을 장면(다양한 부동산) + HUD + 내 평가액 + 목표 패널 + 차트 + 보유 종목
• 3 종목 목록: 종목만 나열. 내 종목 / 전체 탭. 검색창을 누르면 3-1로 이동.
• 3-1 종목 검색: 최근 검색, 인기 종목, 결과, 결과 없음(빈 상태)
• 3-2 사기·팔기: 담기/팔기 전환, 수량, 합계, CTA 하나. 다른 정보는 넣지 않는다.
• 3-3 내 거래 (2026-10-07 추가, ADR 032): 증권사 앱 형태. 실현손익 요약(기간 내, 판 것만) + 매수·매도 금액·거래 건수, 총손익 구성 줄(실현 + 보유 종목 평가), 거래내역 / 종목별 손익 탭, 기간(1주·1달·3달·전체)·구분(전체·매수·매도) 필터, 날짜별 묶음 목록, 빈 상태. 매수·매도 배지는 골드·밤보라(손익색 재사용 금지).
• 4 부동산: 살 수 있는 집 추천 카드, 검색, "살 수 있는 집만" 필터, 모자란 금액 표시. 추천 기준 = 평가액(현금 + 주식 평가액)이 집값의 40% 이상 (나머지 60%는 가짜 대출). 카드 버튼은 3가지 상태: 현금 충분 → "계약하기" / 평가액은 되지만 현금 부족 → "현금 N원 부족 · 주식 팔러 가기"(투자 화면으로 이동) / 평가액도 부족 → "N원 모자라요"
• 5 계약서: 도장 찍기 연출, 변신 알림, 자랑하기 버튼
• 6 내 마을: 집 컬렉션(도감 통합), 다음 변신까지 진행도, 빈 슬롯

MVP 범위 (확정)
• 카카오 로그인, 시드 선택, 대출 60% 구조, 변신 4단계, 도감형 내 마을, 계약서 도장 연출 모두 MVP에 포함한다.
• 일정이 밀리면 줄이는 순서: 계약서 연출 → 변신 연출 → 도감 빈 슬롯. 화면 자체는 유지한다.
• 확정: 주식 매수는 현금으로, 집 추천은 평가액 기준, 집 결제는 현금에서만 차감(자동 매도 없음). 집을 산 뒤에도 주식은 유지.

## 4. 반응형 (웹 + 모바일 웹)
• 기준 폭: 900px. 900px 이상은 데스크톱 레이아웃, 899px 이하는 모바일 웹 레이아웃.
• 네이티브 모바일앱은 MVP 밖이다. 이 규칙은 모바일 브라우저 대응용이다.
• 데스크톱: 상단 헤더에 메뉴 링크. 모바일: 메뉴가 하단 고정 탭 바로 이동.
• 홈·내 마을 같은 장면 중심 화면은 모바일에서 헤더를 접고 HUD 칩을 장면 위에 얹는다.
• 웹 전용 장식(k-wide 스프라이트, 빈 슬롯 등)은 모바일에서 숨긴다.
• 검증 폭: 390px(모바일), 1280px(데스크톱).

## 5. 컬러 토큰
모던 영역
• --bg #F7F8FC / --surface #FFFFFF / --text #1B1B2F / --text-sub #6B6F80 / --line #E6E8F0
픽셀 영역
• --sky #1E90E6 / --night #231B3A / --ink #0F0B1F(픽셀 테두리) / --grass #6CC24A / --soil #7A4B3A
포인트와 상태
• --point #FFC93C (골드, CTA, 평가액 강조)
• --up 흰 배경 위 #D32F36, 어두운 배경 위 #E5484D (수익, 상승=빨강)
• --down 흰 배경 위 #2563EB, 어두운 배경 위 #3B82F6 (손실, 하락=파랑)
• --success #2FBF71 (집 구매 성공)
규칙
• 수익/손실 색은 위 두 개만 쓴다. 다른 용도로 재사용 금지. 단 하나의 예외: 사기·팔기 화면(3-2)의 담기(매수)=--up, 팔기(매도)=--down 버튼 (시안 v0.2, 증권앱 관례).
• 색만으로 구분하지 않는다. 부호(+/-)와 화살표를 같이 쓴다.
• 시안의 밤보라 HUD 칩 + 골드 포인트 조합이 이 게임의 기본 인상이다. 바꾸지 않는다.

## 6. 타이포
• 본문·숫자·차트: Noto Sans KR (시안 사용). 구현 시 Pretendard로 교체해도 됨. 숫자는 tabular-nums.
• 라벨(영문 HUD 라벨): Press Start 2P, 작은 크기에만.
• 한글 도트 제목: Galmuri11 Bold (OFL 라이선스, 상업 사용 가능). 시작 화면 제목과 로고급 제목에만 쓴다.
• 금지: 손익 숫자, 차트 축, 입력창, 설명 문장에는 픽셀 폰트를 쓰지 않는다.
• 시작 화면 제목은 인생역전(골드) / VS(칩) / 인생여전(흰색) 세 덩어리를 세로로 쌓고, 세 덩어리 사이 간격을 같게 둔다(10px 기준, 그림자 보정 포함).

## 7. 간격·모서리·그림자
• 간격은 4/8 단위를 기본으로 쓴다. 시안의 값을 우선한다.
• 모던 카드: radius 16px, 그림자 1단계.
• 픽셀 요소: radius 0, 2~3px 잉크색 테두리, 하단 오프셋 그림자 2~4px.
• 픽셀 이미지는 shape-rendering: crispEdges / image-rendering: pixelated, 정수 배율만 사용.

## 8. 픽셀 스프라이트
• 부동산 종류: 단독주택, 저택, 한옥, 빌라, 타워(고층), 아파트(저층·중층). 한 화면에 아파트만 늘어놓지 않는다.
• 단독주택·저택·한옥·빌라·타워는 홈·시작 화면의 장식용이다. 실제로 사는 대상은 실거래가 기준 아파트뿐이다.
• 색 변주: --roof, --wall, --glass CSS 변수로 같은 스프라이트를 색만 바꿔 쓴다.
• 캐릭터: 꿈이 4단계(걸뱅이/서민/졸부/갑부) 스프라이트. 빈 상태에도 사용.
• 원본 에셋은 직접 제작한 것만 사용한다.

## 9. 컴포넌트 규칙
• HUD 칩: 밤보라 배경 + 골드 숫자. CASH, 장 마감 시계 등.
• 목표 패널: "첫 집 목표 [단지명], 계약금까지 N원 남았습니다" + 진행 바.
• 종목 행: 종목명, 코드, 현재가, 등락률(--up/--down), 보유 수량. 줄 전체가 3-2로 연결.
• 사기·팔기: 담기/팔기 토글, 수량 스테퍼, 살 수 있는 돈(최대 수량), 합계, 큰 CTA 1개.
• 시드 선택 카드: 500만원 / 5,000만원 두 장, 선택한 카드는 골드 배경 + 그림자 확대. CTA 문구는 선택에 따라 바뀐다.
• 부동산 카드: 위에 픽셀 집 썸네일, 아래에 단지명·가격·면적·지역. 내 돈 40% / 대출 60% 표시. 내 돈이 40%에 모자라면 "N원 모자라요".
• 계약서: 종이 질감 카드 + 도장 찍기 인터랙션 + 다시 해보기.
• 빈 상태: 픽셀 캐릭터 + 병맛 한 줄 ("그런 종목은 없어요." 등).

## 10. 모션
• 평가액·시세 변동: 숫자 롤링, 상승은 위로, 하락은 아래로. 0.4초 이내.
• 시세 갱신: 카드 테두리 0.3초 깜빡임(--up/--down).
• 집 구매: 계약서 도장 → 변신 알림 → 내 마을에 집 추가. (낙하·먼지 연출은 시간 남으면)
• 캐릭터는 steps()로 끊어지는 2프레임 바운스.
• prefers-reduced-motion에서는 롤링과 연출을 페이드로 대체.

## 11. 카피 톤
• 과장·병맛. 단 정보 문장(오류, 잔액 부족, 약관)은 명확하게.
• 시작 화면 말풍선: "저 많은 집 중에 내 집이 하나는 있겠지!"
• 모든 화면에 "가짜 돈입니다" 안내를 눈에 띄지 않게라도 유지.
• 변신 단계 이름은 걸뱅이 / 서민 / 졸부 / 갑부.

## 12. 하지 말 것
• 풀 픽셀 UI (숫자·차트까지 픽셀 폰트)
• 보라색 그라데이션, 네온 글로우 남발
• 이모지로 아이콘 대체
• 한 화면에 포인트 컬러 3개 이상
• 비정수 배율 픽셀 확대
• 레퍼런스 게임의 에셋·캐릭터 복제
• 시안에 없는 화면·기능을 임의로 추가

## 13. 에셋 범위 (일정 보호)
• 집 스프라이트 7종 내외(단독주택/저택/한옥/빌라/타워/아파트 2종), 캐릭터 4단계, 배경 1장, 메뉴 아이콘 4~5개. 이 이상은 만들지 않는다.

## 14. 작업 규칙 (도구)
• design-taste-frontend: 구현한 화면을 이 문서 기준으로 점검할 때 사용.
• image-to-code: 구현 참고용 입력은 직접 만든 시안(v0.2)만. 레퍼런스 스크린샷 직접 입력 금지.
• playwright: 구현 후 390px / 1280px 스크린샷을 찍어 이 문서와 시안에 대조.
• 한 번에 한 화면씩. 홈을 먼저 완성하고 규칙을 보정한 뒤 다음 화면으로.
