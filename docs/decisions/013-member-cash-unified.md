# 013. 회원/자금: 1:1 분리 대신 통합

## 상태
확정 (2026-10-03)

## 배경
회원 정보와 자금(현금)을 별도 엔티티로 나눌지 정해야 했음.

## 결정
회원(`Member`)이 현금을 함께 가진다.

## 이유
- 분리할 근거(변경 빈도, 락 범위, 다계좌)가 MVP에서는 약함

## 포기한 대안
- 회원/자금 1:1 분리 (구체적인 장단점은 기록 없음)

## 결과
변경 빈도, 락 범위, 다계좌처럼 분리할 근거가 실제로 생기면 다시 논의한다.
이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 MVP 범위에서 회원/자금 분리를 제안하지 않는다.
