# 050. 플레이 점검 반영: 종목 정보는 숨기고 "오늘 마감" 시계·신규 CTA·HUD 현금 통일

## 상태
확정 (2026-11-06)

## 배경
11/6 로컬 플레이 점검에서 나온 문제
- 종목 정보가 이름·가격·오늘 등락률뿐이라 판단 근거가 약함. 시세는 평균 회귀(029)라 종목 성격과 평소 가격대를 알면 유리함
- HUD의 "장 마감까지" 시계는 고정 목업이고, 시세는 장 시간 없이 24시간 갱신(029)이라 규칙과 맞지 않음. 실제로 하루가 바뀌는 시점은 0시(오늘 시작가·±30% 상하한·일별 평가액 기록, 040·049)
- 신규 회원 홈의 가장 큰 버튼이 "집 보러 가기"라 첫 화면에서 "모자라요"만 보게 됨
- 집 찾기·내 마을 HUD 값이 목업이라 홈·투자의 현금과 다름

## 결정
- 종목 유형·평소 가격(평균 회귀 기준가)은 화면에 공개하지 않음. 플레이어가 가격 흐름을 보고 스스로 성격을 파악하는 것을 재미로 둠 (개발자 결정)
- HUD 시계: "장 마감까지" → "오늘 마감까지", 다음 0시까지 카운트다운 (브라우저 로컬 시각, 한국 사용자 기준)
- 홈 큰 버튼: 보유 종목이 0개면 "첫 종목 사러 가기"(→ 투자), 있으면 "집 보러 가기"
- 홈 손익 차트: 일별 기록이 없으면 빈 차트 대신 "평가액이 쌓이면 그래프로 한눈에 볼 수 있어요" (049 보완)
- HUD는 모든 화면에서 같은 현금(`CASH`). 집 찾기의 현금·평가액은 실제 값으로 계산, 내 마을의 마을 총 가치는 카드에만
- 시세 파라미터(029 초기값)는 런칭 전 플레이 테스트로 확인 후 조정

## 이유
- 규칙을 다 알려주면 발견하는 재미가 사라짐. 대신 스스로 판단하려면 가격 흐름(역대 금액)을 볼 수 있어야 함 → 시세 기록 표시 필요성 높아짐 (progress "런칭 후 과제" 5번 재검토)
- 시계를 실제 규칙(0시 리셋)에 맞추면 "오늘 안에 수익 내기"라는 짧은 목표가 생김
- 신규 사용자의 첫 행동을 종목 사기로 이어줘야 집 → 계약서 → 변신(바이럴 장면)까지 감
- 같은 이름(CASH)의 숫자가 화면마다 다르면 버그로 보임

## 포기한 대안
- 종목 유형·평소 가격 공개("평소보다 12% 쌈", "가격은 평소 가격 쪽으로 돌아오려 해요"): 실력 게임으로 바로 전환, 추세추종 손실 감소 / 정답을 알려줘 재미가 줄고 문구가 게임 분위기와 안 맞음. 구현 후 화면 확인 단계에서 포기 (개발자 판단)
- 장 시간 도입(예: 9~15시만 갱신): 규칙 변경이 큼(029), 밤에 접속한 사용자는 할 게 없음. 포기
- 시계 삭제: HUD 칩 구성이 깨지고 0시 리셋을 알릴 수단이 없어짐. 포기

## 결과
판단 근거는 여전히 가격·오늘 등락률뿐이고, 주문 화면 차트는 화면에 들어온 뒤의 가격만 보여줌 → 시세 기록 표시 범위를 개발자와 결정해야 함. 난이도는 플레이 테스트에서 확인.
이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 종목 유형·기준가를 화면에 노출하자고 다시 제안하지 않는다. 관련: 029, 040, 041, 049.
