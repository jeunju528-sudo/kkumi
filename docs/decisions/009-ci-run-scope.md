# 009. CI 실행 범위: 변경 경로만 대신 항상 전체 실행

## 상태
확정 (2026-10-03)

## 배경
CI 잡 `backend`, `frontend`를 브랜치 보호 규칙의 필수 체크로 등록해 merge 조건으로 쓸 예정이었음.

## 결정
모든 잡을 PR마다 항상 실행한다. 워크플로에 `paths` 필터를 쓰지 않는다.

## 이유
- 잡 하나가 몇 분 수준이고 Gradle·npm 캐시가 있음
- 일정이 빡빡한 1인 프로젝트라 CI 설정 문제로 막히는 게 더 손해

## 포기한 대안
- 변경 경로만 실행(paths 필터): 안 바뀐 쪽을 건너뛰어 빠르고 절약됨 / 필수 체크가 skip되면 PR이 pending에 걸려 merge할 수 없음

## 결과
매번 백엔드와 프론트를 모두 돌림 (감수).
이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 워크플로에 `paths` 필터를 추가하지 않고, 잡 이름(`backend`, `frontend`)을 바꾸지 않는다. 관련: 007, 010.
