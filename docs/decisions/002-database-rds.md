# 002. 운영 DB: EC2 내 MySQL 컨테이너 대신 RDS 사용

## 상태
확정 (2026-10-03)

## 배경
운영 MySQL을 어디에 둘지 정해야 했음.

## 결정
운영은 RDS를 사용하고, 로컬 개발은 `docker-compose.local.yml`의 MySQL 컨테이너를 사용한다. 운영 compose는 앱 + nginx만 포함한다.

## 이유
- 실제 런칭할 서비스라 데이터 안전성이 우선
- 백업·장애 대응을 관리형 서비스에 맡길 수 있음

## 포기한 대안
- EC2 내 MySQL 컨테이너: 무료이고 단순 / EC2 장애 시 데이터가 위험하고 백업을 직접 관리해야 함

## 결과
RDS 비용이 발생함 (감수).
이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 운영 `docker-compose.yml`에 DB 컨테이너를 넣지 않는다.
