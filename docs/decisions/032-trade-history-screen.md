# 032. 거래내역 화면: 투자 화면 탭 대신 별도 화면 (증권사 앱 형태)

## 상태
확정 (2026-10-07)

## 배경
시안 v0.2 10개 화면에 거래내역과 실현손익을 보는 화면이 없었음. 홈 평가액 카드의 시드 대비 손익은 판 것과 안 판 것이 섞인 총손익이라, "판 것으로 얼마 벌었나"와 "언제 무엇을 사고팔았나"를 볼 곳이 필요했음. 데이터는 `TradeHistory`(구분, 체결가, 수량, 실현손익, 거래 시각)에 이미 있음 (ADR 011, 012).

## 결정
"3-3 · 내 거래" 화면을 별도로 추가한다 (`/trade/history`). 실현손익 요약, 총손익 구성(실현 + 보유 종목 평가), 거래내역 / 종목별 손익 탭, 기간(1주·1달·3달·전체)·구분(전체·매수·매도) 필터, 빈 상태로 구성한다. 진입은 투자 화면 "내 종목 평가액" 카드와 홈 "내 평가액" 카드의 링크.

## 이유
- 증권사 앱과 같은 형태라 사용자가 따로 배우지 않아도 됨
- 단순 조회 화면이고 데이터가 이미 있어 화면 공수가 작음
- MVP ② "평가액·손익"을 보강하는 범위라 새 기능이 아님
- 매수·매도 배지는 골드·밤보라. 빨강·파랑은 손익 전용 색이라 재사용하지 않음 (`design.md` 5)

## 포기한 대안
- 투자 화면에 "거래내역" 탭 추가: 새 화면·라우트가 필요 없음 / 기간 필터, 종목별 합계까지 넣으면 탭 하나가 답답함. 개발자가 증권사 앱에 가까운 형태를 선택해 포기

## 결과
백엔드 조회 API가 늘어남: 기간 필터 + 구분 필터 거래 목록(페이징), 기간 내 실현손익·매수·매도 합계, 종목별 실현손익 집계 (감수). 실현손익 계산은 매도 처리 안에서 하므로 심장 ①에 포함.
종목별 손익 수익률은 실현손익 ÷ 판 수량의 매입 원가로 계산. 화면 목업은 원가를 상수로 들고 있고, 실제 응답 형태는 API 설계 때 정함 (기록 없음).
이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 이 화면을 투자 화면 탭으로 합치는 변경을 먼저 제안하지 않는다. 관련: 011, 012.
