# 006. 규칙 강제: 문서만 두지 않고 코드(린터·테스트·훅)로 강제

## 상태
확정 (2026-10-03)

## 배경
CLAUDE.md의 규칙을 사람과 에이전트 모두 놓칠 수 있음.

## 결정
규칙을 ArchUnit 테스트, ESLint, Git 훅으로 옮겨 코드로 강제한다.

## 이유
- 문서에만 있는 규칙은 잘 지켜지지 않음
- 위반하면 커밋 자체가 막힘

## 포기한 대안
- 문서만: 작성이 쉬움 / 사람과 에이전트 모두 놓침

## 결과
설정 유지 비용이 들고 문서와 동기화가 필요함 (감수).
규칙을 추가·변경할 때 CLAUDE.md와 `ArchitectureTest` / `eslint.config.js`를 같이 수정한다. 이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 훅을 우회(`--no-verify`)하지 않는다. 관련: 007, 008, 009.
