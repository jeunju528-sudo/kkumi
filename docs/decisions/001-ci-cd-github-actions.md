# 001. CI/CD: Jenkins 대신 GitHub Actions 사용

## 상태
확정 (2026-10-03)

## 배경
빌드·테스트·배포를 자동화할 CI/CD 수단이 필요했음. 운영 환경은 AWS(EC2 + RDS).

## 결정
GitHub Actions를 사용한다.

## 이유
- 서버가 필요 없고, YAML 하나로 구성하며, GitHub와 연동됨
- 1인 프로젝트라 CI 서버 운영 비용이 더 큼

## 포기한 대안
- Jenkins: 커스터마이징이 자유로움 / 별도 서버가 필요하고 메모리를 많이 써서 작은 인스턴스에서 앱과 같이 돌리기 부담

## 결과
복잡한 파이프라인에는 제약이 있음 (감수).
이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 CI/CD 작업 시 Jenkins 등 별도 CI 서버 도입을 제안하지 않는다.
