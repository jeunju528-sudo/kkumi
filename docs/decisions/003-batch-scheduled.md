# 003. 실거래가 배치: Spring Batch 대신 @Scheduled 사용

## 상태
확정 (2026-10-03)

## 배경
국토부 실거래가를 주기적으로 수집해 저장하는 배치가 필요했음.

## 결정
`@Scheduled`를 사용한다.

## 이유
- 하루 1번 API를 호출해 저장하는 규모
- IPO 프로젝트에서 Spring Batch를 써봤는데 이 정도 규모에는 오버킬
- 설정이 거의 필요 없음

## 포기한 대안
- Spring Batch: 재시작, 청크 처리, 이력 관리를 제공 / 메타 테이블과 Job·Step 설정 부담

## 결과
실패 시 재처리를 직접 구현해야 함 (감수). 배치 수집 로직은 직접 작성 영역(심장 ③)이라 은주가 작성한다.
이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 실거래가 배치에 Spring Batch 도입을 제안하지 않는다. 관련: 017.
