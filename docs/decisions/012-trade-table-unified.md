# 012. 매수/매도 테이블: 분리 대신 통합 (trade_type)

## 상태
확정 (2026-10-03)

## 배경
매수와 매도 거래 내역을 어떻게 저장할지 정해야 했음.

## 결정
하나의 테이블(`TradeHistory`)에 저장하고 `trade_type`(`TradeType`)으로 매수/매도를 구분한다.

## 이유
- 매수와 매도의 컬럼이 같음
- 거래 내역을 시간순으로 조회하기 편함

## 포기한 대안
- 매수/매도 테이블 분리 (구체적인 장단점은 기록 없음)

## 결과
이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 매수/매도 테이블 분리를 제안하지 않는다.
