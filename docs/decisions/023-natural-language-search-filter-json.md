# 023. 자연어 아파트 검색: SQL 직접 생성 대신 필터 JSON

## 상태
확정 (2026-10-03)

## 배경
자연어 아파트 검색은 10/17까지 MVP 4개가 실서버에서 동작할 때만 추가하는 조건부 기능임. 구현한다면 LLM을 어떻게 쓸지 정해야 했음.

## 결정
LLM은 사용자 입력에서 필터만 추출해 JSON으로 돌려주고, 쿼리는 코드에서 생성한다.

## 이유
- 사용자 입력을 예측할 수 없으므로 LLM은 필터만 추출하게 하고 쿼리는 코드에서 만드는 편이 안전함

## 포기한 대안
- LLM이 SQL을 직접 생성: 사용자 입력을 예측할 수 없어 포기

## 결과
이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 LLM이 SQL을 직접 생성하는 설계를 제안하지 않는다. 관련: 021.
