# 063. 알림 읽음: 줄을 누른 1건만 읽음 + 모두 읽음 버튼

## 상태
확정 (2026-11-19)

## 배경
알림 목록 드롭다운(`docs/design.md`)은 줄마다 안 읽음 골드 점을 표시하고, 종에는 안 읽은 수 배지를 단다. 알림함 API(PR 4)를 만들면서 언제 읽음으로 바꿀지 정해야 했다.

## 결정
줄을 눌러 주문 화면으로 갈 때 그 1건만 읽음(`POST /api/notifications/{id}/read`). 한 번에 정리하는 "모두 읽음"(`POST /api/notifications/read-all`)을 따로 둔다.

## 이유
- 골드 점이 "아직 확인 안 한 종목"이라는 의미를 유지함. 열기만 해도 전부 읽으면 점이 열자마자 사라져 장식이 됨
- 알림이 쌓였을 때 하나씩 누르지 않아도 되도록 모두 읽음 제공
- 읽음은 멱등: 이미 읽은 알림은 처음 읽은 시각 유지(`Notification.markAsRead`). 모두 읽음은 `readAt is null` 조건 벌크 update 1번

## 포기한 대안
- 드롭다운을 열면 전부 읽음: 구현이 단순하고 요청이 1번 / 줄별 안 읽음 표시가 의미 없어짐
- 읽음 없이 배지만 0으로: 서버에 읽음 상태가 없어 다른 기기·새로고침에서 배지가 되살아남

## 결과
- 줄 클릭 때 요청 1번이 늘어남(읽음 → 주문 화면 이동)
- 남의 알림 id는 403 대신 404(`NOTIFICATION_NOT_FOUND`)로 존재 여부를 숨김
- 보관은 오늘 포함 7일, 매일 3시 `NotificationCleanupScheduler`가 벌크 delete
이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 드롭다운 열기만으로 읽음 처리하는 코드를 제안하지 않는다.
