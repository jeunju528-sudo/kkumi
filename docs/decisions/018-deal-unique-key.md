# 018. 거래 유니크 키: (단지 id, 전용면적, 층, 거래금액, 계약일)

## 상태
확정 (2026-10-03)

## 배경
국토부 데이터에 거래 고유번호가 없어서, 증분 upsert(017)를 하려면 중복을 판별할 키를 직접 정해야 했음.

## 결정
`AptDeal`의 유니크 키를 (단지 id, 전용면적, 층, 거래금액, 계약일)로 한다. 해제여부는 키에서 제외한다.

## 이유
- 거래 고유번호가 없음
- 해제여부는 나중에 값이 바뀌므로 키에 넣을 수 없음

## 포기한 대안
- 해제여부를 포함한 키: 값이 나중에 바뀌어 같은 거래가 다른 거래로 취급됨

## 결과
동(棟) 정보가 없어서 동만 다른 같은 조건의 거래는 하나가 누락됨 (드묾, 감수).
이 결정을 번복하려면 먼저 은주와 논의 필요. 에이전트는 이 키를 임의로 바꾸지 않는다. 관련: 017.
