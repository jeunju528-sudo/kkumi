# 008. 백엔드 아키텍처 검사: 리뷰만 하지 않고 ArchUnit 사용

## 상태
확정 (2026-10-03)

## 배경
계층·엔티티 규칙(Controller → Service → Repository, 엔티티 setter 금지 등)이 지켜지는지 확인할 수단이 필요했음.

## 결정
ArchUnit으로 `ArchitectureTest`를 작성해 규칙을 테스트로 강제한다.

## 이유
- 계층·엔티티 규칙은 패턴이 명확해서 테스트로 잡기 좋음

## 포기한 대안
- 리뷰만: 추가 의존성이 없음 / 놓치기 쉬움

## 결과
테스트 의존성이 1개 늘어남 (감수). 코드로 못 잡는 규칙(네이밍, boolean 접두사 등)은 PR 리뷰에서 확인한다.
이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 백엔드 규칙을 추가·변경할 때 `ArchitectureTest`도 함께 수정한다. 관련: 006.
