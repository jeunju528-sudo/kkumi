# 024. 새 기술 상한선: 현재 기술 목록 이상 추가하지 않음

## 상태
확정 (2026-10-03)

## 배경
런칭일(2026-10-24)이 고정이고, 1인 프로젝트이며, MVP는 4개로 제한되어 있음. 일정이 밀리면 기능을 줄이는 원칙이라 기술이 늘수록 일정 위험이 커짐.

## 결정
Kafka, Kubernetes, Redis, Elasticsearch, MSA, Next.js, 전역 상태관리 라이브러리(Redux, Zustand 등)를 추가하지 않는다. 기술 스택은 CLAUDE.md의 "프로젝트 개요"에 적힌 목록까지로 한다.

## 이유
- 런칭일이 고정이고 일정이 밀리면 기능을 줄이는 원칙
- 1인 프로젝트라 운영·학습 부담을 늘리지 않는 것이 우선
- MVP 4개를 실서버에서 동작시키는 것이 먼저

## 포기한 대안
- 위 기술들 도입 (기술별 장단점은 기록 없음). Elasticsearch는 MVP 이후("나중에") 목록에 있음

## 결과
새 기술이 필요해 보이면 도입을 제안하기 전에 이유를 설명하고 은주와 협의한다.
에이전트는 이 기술들의 도입을 먼저 제안하지 않는다. 매수 동시성은 이 결정에 따라 Redis 락 대신 비관적 락으로 정했다 (025). 관련: 021, 022.
