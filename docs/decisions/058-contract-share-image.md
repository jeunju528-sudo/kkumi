# 058. 계약서 공유 이미지: html-to-image + Web Share API, 실패 시 미리보기

## 상태
확정 (2026-11-13)

## 배경
- 계약서 "계약서 캡처해서 자랑하기", 내 마을 "친구한테 자랑하기" 버튼이 시안 옮길 때 모양만 있고 동작이 없었음
- 휴대폰(iPhone 16)에서 직접 캡처하면 계약서가 한 화면보다 길고 하단 탭바가 아래를 가려 잘림
- 캡처해서 자랑하는 바이럴이 게임의 무기라 런칭 전에 정리 필요

## 결정
- 계약서 버튼: 계약서 종이 영역(`.contract-paper`)만 `html-to-image`의 `toBlob`(pixelRatio 2)으로 PNG 변환 → `navigator.share({ files })`로 공유 시트(사진 저장, 메신저 전송)
- 공유 시트가 없거나(PC 브라우저) 공유가 실패하면(사파리 사용자 동작 시간 초과 등) 이미지 미리보기 창: 길게 눌러 저장 + 내려받기 링크. 공유 시트를 닫은 것(AbortError)은 아무것도 안 함
- 사파리 첫 변환에서 폰트·이미지가 빠지는 경우가 있어 2번 변환 후 두 번째 결과 사용
- 로직은 `hooks/useShareImage`(변환·공유·미리보기 상태), 화면은 `ContractPage`
- 내 마을 "친구한테 자랑하기" 버튼은 삭제 (개발자 결정)
- 작성 분담: 개발자 요청으로 프론트 동작까지 에이전트 작성, 개발자 리뷰 (045 예외, 056과 같은 방식)

## 이유
- DOM을 그대로 이미지로 만들어 화면 길이와 무관하고, 시안 디자인을 다시 그릴 필요 없음
- Web Share API는 브라우저 기본 기능이라 추가 설치 없이 아이폰 공유 시트를 띄움
- 미리보기 대안을 두어 공유 시트를 못 쓰는 환경에서도 저장 가능

## 포기한 대안
- 캔버스에 직접 그리기: 새 의존성 없음 / 표·글자를 좌표로 다시 그려야 해서 150줄 이상, 디자인 변경 때마다 같이 수정. 런칭 일정상 포기
- 글 + 링크만 공유: 10줄 / 이미지가 없어 자랑 효과 약함
- 사용자 직접 캡처 안내: 구현 없음 / 잘림 문제 그대로

## 결과
- 새 패키지 `html-to-image`(MIT, 의존성 없음) 추가. 기술 상한선(024) 예외로 개발자 동의 (2026-11-13)
- Google Fonts(Noto Sans KR)는 다른 출처라 변환 때 글꼴 파일을 다시 받아 첫 변환이 느릴 수 있고, 실패하면 이미지 속 한글이 기기 기본 글꼴로 바뀜. 실제 아이폰에서 확인 후 판단
- 이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 공유용 이미지 라이브러리를 개발자 동의 없이 바꾸거나 추가하지 않는다.
