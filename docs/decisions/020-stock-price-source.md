# 020. 주식 시세 출처: 서버가 만드는 가상 시세 (KIS·공공데이터 시세 포기)

## 상태
확정 (2026-10-06)

## 배경
실시간 평가액(MVP ②)을 보여주려면 시세가 필요했다. 2026-10-06에 검토한 두 출처가 모두 서비스 이용자에게 보여주는 용도로는 쓸 수 없음을 확인했다.
- KIS(한국투자증권) 답변
  - 시세는 개인 고객 본인의 자산운용 투자 목적에 한해 활용 가능하고, 제3자 제공과 목적 외 사용은 제한됨
  - 로그인한 소수의 사용자에게 제공하는 것도 제3자 제공에 포함됨
  - 불특정 다수가 쓰는 앱·웹 서비스 배포는 허용되지 않음
  - 일반 법인이 시세를 쓰려면 코스콤과 별도 정보이용계약이 필요함
- 공공데이터포털 금융위원회 주식시세정보
  - 공공누리 4유형(출처표시, 상업적 이용 금지, 변경 금지)
  - 상업적 목적 여부와 상관없이 제3자 무단 제공·재배포가 엄격히 금지됨
  - 상업적 이용은 한국거래소 KRX Data Marketplace에서 유료 구매해야 하고, 그때도 허용 목적이 제한됨
  - 갱신은 일 1회, 기준일 영업일 하루 뒤 오후 1시 이후 (실시간 아님)

## 결정
외부 시세 데이터를 쓰지 않고 서버가 만드는 가상 시세를 쓴다.
- 종목은 실제 기업과 무관한 가상 종목(가상 이름·코드)으로 한다. 이름 목록은 에이전트가 제안하고 개발자가 확정한다
- 종목별 시작 금액대는 개발자가 정하는 설정값이다
- 가격 변동 방식은 ADR 029를 따른다
- 외부 시세 데이터는 시세 값으로도, 금액대 보정용 입력으로도 자동 수집하지 않는다
- 시세 조회는 `StockPriceProvider` 인터페이스로만 하고, 구현체를 `MockPriceProvider`에서 가상 시세 구현체로 바꾼다

## 이유
- KIS와 공공데이터 모두 약관상 이용자 화면 제공이 불가함
- 외부 시세 데이터를 쓰지 않으면 약관 문제가 없음
- 서비스 전체가 가짜 돈으로 하는 게임이라 가상 시세여도 컨셉에서 크게 벗어나지 않고, 평가액·WebSocket 푸시(MVP ②)를 그대로 유지할 수 있음
- `StockPriceProvider`로 분리해둬서, 나중에 합법적인 출처가 생기면 구현체만 교체하면 됨
- 종목을 가상으로 한 이유: 이 서비스는 결과 화면을 캡처해서 공유하는 것이 전략인데, 가상 시세를 실제 기업 이름에 붙이면 "OO전자 폭락" 같은 화면이 설명 없이 퍼져 허위 시세로 오해될 수 있음. 화면 안의 표기는 캡처에 남지 않을 수 있음

## 포기한 대안
- 실제 종목명에 가상 시세 사용 (2026-10-07 개발자 결정으로 가상 이름 유지): 이름 자체는 사실 정보라 쓸 수 있을 가능성이 높음 / 위의 오해와 실제 기업 평판 문제가 남음. 상표·약관 판단은 기록 없음. 종목 목록을 공공데이터 금융위원회 주식발행정보에서 받으면 공공누리 2유형(출처표시, 상업적 이용 금지) 조건이 적용됨. 포기
- KIS Open API 시세: 장중 시세를 받을 수 있음 / 제3자 제공 불가. 포기 (`docs/failures/001-kis-stock-price-api.md`)
- 공공데이터 주식시세정보(전일 종가 + 연출 변동): 제3자 제공 금지, 변경 금지에 걸림. 포기 (`docs/failures/002-public-data-stock-price.md`)
- KRX Data Marketplace 유료 구매: 허용 목적이 제한됨. 가격과 이 게임이 허용 목적에 해당하는지는 기록 없음. 문의 여부는 개발자가 정하고, MVP에는 쓰지 않음
- 키움 등 다른 증권사 Open API: 약관을 확인하지 않아 기록 없음

## 결과
- "실제 종목에 투자"하는 컨셉이 "가상 종목에 투자"로 바뀜. 게임 소개 문구는 개발자가 정함
- 가상 종목이라 실제 종목으로 오해할 일은 줄지만, 가상 이름이 실제 기업·상표와 겹치는지는 확인 기록 없음
- 가상 시세 변동 방식은 ADR 029에서 정함
- 이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 외부 시세 데이터(증권사 Open API, 공공데이터 주식시세정보 등)를 시세 값이나 보정 입력으로 자동 수집하자고 제안하지 않고, 약관을 확인하기 전에는 새 시세 출처를 제안하지 않는다. 가상 시세를 실제 시세처럼 보이게 하는 화면 문구를 제안하지 않는다. 시세는 `StockPriceProvider`로만 호출한다 (CLAUDE.md).
