# 020. 주식 시세 출처: 공공데이터 전일 종가 + 연출용 장중 변동 (KIS 포기)

## 상태
확정 (2026-10-06)

## 배경
실시간 평가액(MVP ②)을 보여주려면 장중 시세가 필요했다. KIS에 시세 재배포 약관을 문의했고, 2026-10-06 한국투자증권 답변이 왔다.
- 시세는 개인 고객 본인의 자산운용 투자 목적에 한해 활용 가능하고, 제3자 제공과 목적 외 사용은 제한됨
- Open API는 본인 명의 앱키로만 이용 가능하며, 로그인한 소수의 사용자에게 정보를 제공하는 것도 제3자 제공에 포함됨
- 불특정 다수가 쓰는 앱·웹 서비스 배포는 허용되지 않음
- 일반 법인이 시세를 쓰려면 코스콤과 별도 정보이용계약이 필요함

## 결정
시세는 공공데이터의 실제 전일 종가를 기준값으로 쓰고, 장중 움직임은 서버가 종가를 기준으로 만든 연출용 변동으로 보여준다. 화면에는 연출용 시세임을 표기한다. KIS를 포함한 증권사 Open API 시세는 서비스에 쓰지 않는다.
시세 조회는 `StockPriceProvider` 인터페이스로만 하고, 구현체(종가 + 연출 변동)로 교체한다.

## 이유
- KIS 답변상 증권사 Open API 시세를 서비스 이용자에게 보여주는 방식은 로그인 사용자 한정이어도 허용되지 않음
- 평가액·손익이 장중에도 움직여야 MVP ②(실시간 갱신)와 실시간 평가액 차트(심장 ④)가 의미를 가짐
- 서비스 전체가 가짜 돈으로 하는 게임이라 장중 변동을 연출로 처리해도 컨셉에 어긋나지 않음. 단 실제 시세로 오해하지 않게 표기가 필요함
- 공공데이터 종가는 기존 검토에서 약관 문제가 없다고 기록됨. 이용허락범위와 갱신 시점은 개발자가 포털에서 확인 전 (기록 없음)

## 포기한 대안
- KIS Open API 시세: 장중 시세를 받을 수 있고 자료가 많음 / 제3자 제공 불가. 포기 (`docs/failures/001-kis-stock-price-api.md`)
- 키움 등 다른 증권사 Open API: 약관을 확인하지 않아 장단점 기록 없음. 쓰려면 약관 확인이 먼저
- 코스콤 정보이용계약: 일반 법인 대상 계약. 비용·절차는 기록 없음. 런칭 일정(10/24) 안에 진행하지 않음
- 공공데이터 종가만 그대로 사용: 약관 문제 없음 / 하루 1번만 바뀌어 실시간 평가액이 의미 없어짐. 포기

## 결과
- 화면 시세는 실제 장중 시세와 다름. 연출용 표기가 필요하고 표기 문구는 개발자가 `docs/design.md` 기준으로 정함
- 연출 변동 방식(생성 규칙, 사용자 간 동일 값 여부, 갱신 주기)은 미정. `decisions/README.md` "미정"에서 정하고 ADR로 남김
- 일정이 밀리면 연출 변동을 빼고 종가만 보여주는 쪽으로 줄이는 안을 개발자와 논의함
- 이 결정을 번복하려면 먼저 개발자와 논의 필요. 에이전트는 KIS 등 증권사 Open API 시세를 서비스 시세로 쓰자고 제안하지 않고, 로그인 사용자 한정·서버 공용 키 중계 같은 우회 방식도 제안하지 않는다. 시세는 `StockPriceProvider`로만 호출한다 (CLAUDE.md). 연출용 시세를 실제 시세처럼 보이게 하는 화면 문구를 제안하지 않는다.
