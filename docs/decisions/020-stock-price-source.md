# 020. 주식 시세 출처: KIS vs 키움 vs 공공데이터(전일 종가)

## 상태
검토 중 (KIS에 시세 재배포 약관 문의 중)

## 배경
실시간 평가액을 보여주려면 장중 시세가 필요함. KIS에 시세 재배포 약관을 문의했고, 답변 전까지는 `MockPriceProvider`로 개발한다.

## 후보
- 공공데이터(전일 종가): 약관 문제가 없음 / 하루 1번 갱신이라 실시간 평가액이 의미 없음
- KIS: 장중 시세를 받을 수 있고 자료가 많음 / 시세 재배포가 제한될 가능성
- 키움: 후보로만 기록됨 (구체적인 장단점은 기록 없음)

## 결정
KIS를 검토 중이며 약관 답변이 오면 KIS 구현체 또는 공공데이터 종가로 결정한다.
이미 확정된 대응: `StockPriceProvider` 인터페이스로 분리(KIS / Mock)하고, 시세는 로그인 사용자에게만 노출한다.

## 결과
최종 출처는 약관 답변 이후 은주가 결정한다. 에이전트는 시세를 `StockPriceProvider` 인터페이스로만 호출하고 KIS 클라이언트를 직접 호출하지 않는다 (CLAUDE.md).
