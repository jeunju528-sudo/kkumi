# 001. KIS Open API 시세를 서비스에 사용 (포기)

## 시도한 날짜
2026-10-06 (KIS 문의 답변 확인일. 문의 시작일은 기록 없음)

## 시도한 이유
실시간 평가액(MVP ②)을 보여주려고 장중 시세가 필요했고, KIS Open API로 시세를 받아 사용자에게 보여줄 수 있는지 약관을 문의함

## 실패 원인
- 시세는 개인 본인의 자산운용 투자 목적에 한해 사용 가능하고 제3자 제공은 제한됨
- 로그인한 소수의 사용자에게 시세를 보여주는 것도 제3자 제공에 포함됨
- 불특정 다수가 쓰는 앱·웹 서비스 배포는 허용되지 않음
- 서비스 목적으로 쓰려면 코스콤과 별도 정보이용계약이 필요한데, 일반 법인 대상임

## 현재 대안
서버가 만드는 가상 시세 (`decisions/020`). 공공데이터 주식시세정보도 약관상 불가 (`failures/002`)

## 에이전트 지침
KIS Open API 시세(및 다른 증권사 Open API 시세)를 서비스 시세로 쓰자고 제안하지 않는다. 로그인 사용자 한정 노출, 서버 공용 키 중계로 우회하자는 제안도 하지 않는다. 다른 증권사 API를 검토할 때는 약관 확인이 먼저다.
