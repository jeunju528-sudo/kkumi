# 002. 공공데이터 주식시세정보를 서비스 시세로 사용 (포기)

## 시도한 날짜
2026-10-06 (이용 조건 확인일)

## 시도한 이유
KIS 시세를 쓸 수 없게 된 뒤, 공공데이터포털 금융위원회 주식시세정보의 전일 종가를 기준값으로 쓰고 장중 움직임을 연출 변동으로 만드는 안을 검토함

## 실패 원인
- 공공누리 4유형(출처표시, 상업적 이용 금지, 변경 금지). 연출 변동으로 가공하는 것은 변경 금지에 걸림
- 상업적 목적 여부와 상관없이 제3자 무단 제공·재배포가 엄격히 금지됨. 이용자 화면에 보여주는 것은 제3자 제공에 해당
- 상업적 이용은 KRX Data Marketplace 유료 구매가 필요하고 허용 목적도 제한됨
- 갱신이 일 1회, 기준일 영업일 하루 뒤 오후 1시 이후라 실시간성도 없음
- 기존 ADR 020에 "약관 문제 없음"이라고 기록돼 있었으나 확인 없이 쓴 내용이었음

## 현재 대안
서버가 만드는 가상 시세 (`decisions/020`)

## 에이전트 지침
공공데이터 주식시세정보를 시세 값이나 가상 시세의 보정 입력으로 쓰자고 제안하지 않는다. 외부 데이터를 사용하자고 제안하기 전에 이용허락범위와 제3자 제공 조건을 먼저 확인한다.
