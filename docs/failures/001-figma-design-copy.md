# 001. Figma 사본으로 시안 전체 옮기기 미완

## 시도한 날짜
2026-10-03 이전 (정확한 날짜는 기록 없음)

## 시도한 이유
Claude Design 시안 v0.2를 Figma 사본으로도 옮기려 함. (구체적인 목적은 은주 확인 필요)

## 실패 원인
- Figma 무료 플랜의 MCP 호출 한도 때문에 일부 화면을 옮기지 못함
- 완료: 데스크톱 10개, 모바일 7개
- 미완: 모바일 사기·팔기, 계약서, 내 마을

## 현재 대안
UI 기준은 Claude Design 시안 v0.2와 `docs/design.md`, `docs/ui-spec.md`. Figma 사본은 기준이 아니다.

## 에이전트 지침
Figma 사본을 UI 기준으로 삼지 않는다. 남은 모바일 화면을 Figma MCP로 옮기자고 먼저 제안하지 않는다 (무료 플랜 호출 한도).
